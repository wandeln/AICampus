🎯 Multiple-Choice-Fragen

Je Frage: Punkte, Single-/Mehrfachauswahl und Antwortoptionen. Das Feedback je Option ist optional — bei leerem Feld zeigt das System nach dem Einreichen einfach „Richtig“/„Falsch“. Bei Fragen mit Mehrfachauswahl gibt es je Option zwei Feedback-Felder (korrekt bzw. falsch beantwortet); ein leerer „korrekt beantwortet“-Eintrag bei einer falschen Option bleibt nach dem Einreichen einfach ohne Kommentar. Bei Single-Auswahl ein Feld (erscheint, wenn die Option ausgewählt wird). „Max. Punkte“ wird automatisch aus den Fragen summiert.

0 P gesamt
