📝 Markdown-Anleitung für Folien

Folien & Unterfolien
  • --- (eigene Zeile) → neue Folie
  • -- (eigene Zeile) → vertikale Unterfolien (in der Präsentation mit ↓ nacheinander); jede Unterfolie ist wie eine normale Folie (eigene Direktiven, notes, Hintergrund)
Direktiven (je eigene Zeile am Folienanfang)
  • layout: center|topleft
  • transition: fade|slide|zoom|none|autoanimate — Default autoanimate (Inhalt animiert zwischen den Folien ineinander; gezoomte Applets {zoom=X} überspringt das Auto-Animate); fade/slide/zoom/none = klassische Transition
  • class: <kennung>
  • notes: <Sprechernotiz>
  • background: ![Titel](/media/…) → vollflächiger Folien-Hintergrund (Bild oder .html-Applet; Applets bleiben klickbar) — .html wird beim PDF-Export nicht mitgedruckt
Spalten (auch verschachtelt)
  • @startcolumn[:gewicht] … @nextcolumn[:gewicht] … @endcolumn — Marker je eigene Zeile am Zeilenanfang; Gewicht = positive Zahl (Default 1) = Breitenanteil (z. B. @startcolumn:2 / @nextcolumn:1 = 2:1)
  • Zellen-Inhalt = normales Markdown; weitere Spaltenzeilen darin = verschachtelte Spalten; Inhalt VOR @startcolumn (z. B. Überschrift) bleibt vollbreit über der Zeile
  • 2–4 Spalten pro Zeile sinnvoll
Schrittweises Einblenden (Fragments)
  • {% raw %}{#fragment}{% endraw %} am Zeilenende (z. B. nach Bullet, Absatz oder Formel)
  • {% raw %}{#fragment:id}{% endraw %} → alle Elemente mit gleicher ID erscheinen gleichzeitig
  • {% raw %}{#Fragment}{% endraw %} (Großbuchstabe) → Element + alle folgenden Inhalte der Folie erscheinen erst mit einem Klick
  • In Formeln: {% raw %}\htmlClass{fragment}{…} / \htmlClass{fragment:id}{…}{% endraw %} → der eingewickelte Teil erscheint erst mit einem extra Klick (gleiche id = gleichzeitig)
Medien (Bilder, Applets, YouTube)
  • {height=400} → Max-Bildhöhe in px (Suffix px und führender Punkt optional), direkt nach dem Bild-/Applet-Snippet
  • {zoom=1.5} → Applet-Zoom, direkt nach dem Snippet
  • Externe Websites & YouTube-Links (watch?v=…, youtu.be/…, shorts/…) werden automatisch eingebettet (16:9-Embed-Player); {height=…} fixiert die Iframe-Höhe (Breite proportional)
  • Alt-Text steht immer als Unterschrift unter dem Medium (mit Label: „Abb. N: Text“, ohne Label: ohne Nummer)
Hervorheben
  • @startbox:highlight … @endbox → transparenter, geblurter Bereich in der Primärfarbe (z. B. für Titel auf Deckslides)
  • @boxcolor:<farbe> als erste Zeile → Boxfarbe übersteuern (Hex, rgb()/rgba(), CSS-Farbname)
Auto-Animate
  • {% raw %}{#aaid:label}{% endraw %} am Zeilenende (oder nach $$…$$/{% raw %}{#eq:…}{% endraw %}/Bild-Snippet) → Elemente mit demselben Label auf zwei Folien animieren per ID ineinander
Code-Blöcke
  • Fenced-Block mit Sprache auf der öffnenden Zeile → syntax-highlightet
  • Tokens direkt nach der Sprache (Reihenfolge frei, auch ohne Leerzeichen):
  • {% raw %}{#lines:1,3-5}{% endraw %} → Zeilennummern + schrittweises Zeilen-Einblenden (| = weiterer Schritt)
  • {% raw %}{#aaid:label}{% endraw %} → Auto-Animate-ID (gleiche Label auf zwei Folien → Zeilen animieren ineinander)
  • {% raw %}{.zoom=1.5}{% endraw %} → größere Schrift
  • {% raw %}{.height=300}{% endraw %} → Max-Höhe in px + internes Scrollen (ohne {.height} gilt dieselbe Default-Höhe wie bei Applets)
  • {% raw %}{#code:label}[caption]{% endraw %} → nummerierter Code-Block („Code N: caption“, Nummer klickbar, falls das Label auch im Skript vorkommt) + Eintrag in der „Codes“-Tabelle des Skript-IV
  • @startbox:code … @endbox → dunkle Code-Box mit „Code“-Kopf
